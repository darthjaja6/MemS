MemS

Spatial memory for faster agent-as-policy robot control.

General-purpose agents are starting to control robots through images, reasoning, and tool calls. Recent GPT-6 Astra robot demonstrations and Agent as Policy experiments show what this makes possible: an agent can interpret a task, write code, command robot arms, and adjust its actions from feedback, without training a new policy for each task.

But this flexibility is often very slow. Each round of observation, reasoning, and code generation adds time between actions; the Agent as Policy experiments report successful tasks taking tens of minutes. Repeatedly working out object geometry and rewriting spatial calculations adds work to that loop.

MemS targets that repeated spatial work. Build a 3D scene once, then update what changes. The agent reuses stored object geometry and calls existing geometry scripts to calculate subsequent targets, reducing repeated reconstruction and code generation.

How it saves work

Maintain a 3D reconstruction during execution. The agent describes object shapes at the start. The scene retains their geometry, dimensions, and spatial relationships; new observations update their placement as the robot acts.

Estimate positions with a predefined geometry library. The agent selects image measurements. Existing scripts use camera calibration to calculate positions, orientations, and dimensions, then save the results in the scene.

New observations update the same scene

Reusable shape, individual state

Similar objects reference the same asset, with their own position, orientation, scale, and color. Landmarks and shape parameters give calculations concrete features to measure.

Geometry from observations

Scripts use camera calibration and image correspondences to estimate locations and fit dimensions. Multi-view measurements or known surfaces provide geometric constraints. Shape assumptions and measurement uncertainty still matter.

Updates during execution

The agent plans action sequences with observation checkpoints. Measured robot state and attachment transforms can update poses programmatically; new visual measurements correct estimates. Geometry is revised when observations require it.

Implementation

Scene format

Shape definitions live in asset files. scene.json holds instances and spatial state. Planning and visualization read the same geometry.

Robot models supply link geometry and joint relationships. A deployment supplies observations, camera calibration, measured joints, and the interface that executes actions.

Run the viewer

Python 3.11 · From the repository root

python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python demo/app.py

Open 127.0.0.1:8765. Includes the recorded scene, robot models, and replay; no simulator connection is needed.

Use the agent skill

Copy the complete folder into your workspace.

mkdir -p /path/to/workspace/.agents/skills
cp -R skills/spatial-memory \
  /path/to/workspace/.agents/skills/

The skill includes its workflow, calculation scripts, and reference documents. Robot execution requires a configured deployment.
